## ANSWER KEY AND EXPLANATIONS

**Q1. B**
*Explanation:* Groundedness measures how strictly the model's output adheres to the provided source material (the product catalog). This is the direct metric for evaluating hallucinations in a constrained knowledge task.

**Q2. A, C**
*Explanation:* LLM-as-a-judge (A) and Human-in-the-loop (C) are standard ways to evaluate factual consistency. Word count, temperature, and JSON formats do not measure factual correctness.

**Q3. B**
*Explanation:* The only reliable way to validate functional correctness of code is to execute it against test cases (B).

**Q4. A**
*Explanation:* Recall measures how many of the actual entities were successfully extracted. Precision measures how many of the extracted entities were correct. A golden dataset is required for formal evaluation.

**Q5. A, B**
*Explanation:* Automated LLM scoring (A) and A/B testing (B) scale well for tone evaluation. Human linguists (C) do not scale.

**Q6. B**
*Explanation:* Injecting synthetic, known differences into the source and measuring the model's ability to catch them (Recall) is a standard validation technique for anomaly detection / comparison tasks.

**Q7. B**
*Explanation:* Continuous monitoring via user feedback and automated scoring pipelines helps detect data drift or performance degradation over time in live systems.

**Q8. B**
*Explanation:* A Golden Dataset is a highly curated, human-verified set of inputs and expected outputs used as a benchmark to evaluate model performance.

**Q9. A, B**
*Explanation:* BLEU and ROUGE are standard NLP metrics used for evaluating translation and summarization by comparing generated text to reference text.

**Q10. B**
*Explanation:* Models often include conversational filler (e.g., "Here is your JSON:"). This breaks strict JSON parsers. Prefilling or strict prompting is needed.

**Q11. B**
*Explanation:* Human preference (often using Elo ratings or side-by-side A/B blind tests) compares two models against each other.

**Q12. C**
*Explanation:* Repetition/Redundancy rate specifically tracks how often a conversational model repeats previous statements.

**Q13. B**
*Explanation:* LLM-as-a-judge can exhibit biases, such as favoring its own outputs, verbose outputs, or specific formatting, requiring careful prompt tuning for the judge itself.

**Q14. A**

**Q16. A, C**
